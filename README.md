TP Engagement Agent · 转让定价签约助手（演示）
================================================

怎么打开
--------
双击 index.html，用浏览器打开即可。

不需要装任何东西，不需要联网，不需要启动服务器。
建议用 Chrome 或 Edge。

关于这个演示
------------
- 全部资料为虚构数据，与任何真实客户无关。
- 页面顶部有常驻的「演示数据」标识和免责声明，那是刻意保留的。
- 整个流程五步：上传与识别材料 → 核对识别结果 → 确认变更事项
  → 预览与导出合同 → 审计记录。左侧导航的序号就是这五步。
- 从「使用预置演示文件（5 份）」开始，一路点「下一步」即可走完。

可以上传你自己的真实合同
------------------------
在「上传与识别材料」页选择本地文件即可。DOCX 与 XLSX 会被真正解析
（段落、表格、页眉页脚都读），不是只比对文件名。传两份 DOCX
（上年度已签合同 + 本年度标准模板）后会出现「跑真实比对」按钮。

PDF 不支持文本提取 —— 现代 PDF 普遍用字体子集编码，纯前端无法可靠还原。
上传 PDF 会明确提示失败，请改用 DOCX。

会用到网络的只有一处
--------------------
侧栏「模型接入」页可以配置真实大模型端点。不填任何东西时，
整个演示零网络请求、完全离线。这一点可以在浏览器的网络面板里自己验证。

手机上也能看
------------
把这个文件夹放到手机上打开 index.html 同样可用（已做移动端适配）。
不过手机上双击打开本地文件比较麻烦，用电脑更方便。
